    Webhook Integration¶

    Set up real-time automatic synchronization from Zoho Inventory to WooCommerce.

    What Are Webhooks?¶

    Webhooks enable real-time, automatic synchronization. When you create or update an item in Zoho, the change appears in your store within seconds—no manual sync required.

    Enable Webhooks¶

    1. Go to LZ SKU Sync > Sync Status
    2. Find Sync Frequency setting
    3. Select "Always (Real-time webhook)"
    4. Click Save Preferences

    The plugin automatically configures everything in Zoho Inventory - no manual setup needed!

    Webhook Status¶

    Status Indicator¶

    Visual indicator shows webhook status:

    • 🟢 Active (Green): Receiving and processing updates
    • 🔴 Inactive (Red): Webhooks paused

    Toggle Webhook¶

    To pause or resume webhooks:

    1. Click the webhook status indicator
    2. Status toggles between active/inactive
    3. Configuration is preserved when paused

    Active: Products update in real-time when changed in Zoho

    Inactive: Changes in Zoho are ignored until reactivated

    Monitoring Webhooks¶

    Recently Synced Items¶

    Webhook-triggered syncs appear in the "Recently Synced Items" table at LZ SKU Sync > Sync Status.

    Webhook Sync Log¶

    30-day history of webhook events at LZ SKU Sync > Sync Status > Webhook Sync Log.

    Best Practices¶

    Initial Setup¶

    1. ✅ Run manual sync first to import all products
    2. ✅ Verify products synced correctly
    3. ✅ Enable webhook sync for ongoing updates

    Temporary Pause¶

    To pause without losing configuration:

    • Toggle webhook to inactive
    • Make bulk changes in Zoho
    • Toggle back to active
    • Run manual sync to catch changes made while inactive

    Troubleshooting¶

    Webhooks Not Working¶

    Solutions:

    1. ✅ Check sync frequency is "Always (Real-time webhook)"
    2. ✅ Check webhook status indicator is green (active)
    3. ✅ Verify license is active
    4. ✅ Check Zoho Inventory > Settings > Webhooks for errors
    5. ✅ Contact support if issue persists

    Delayed Updates¶

    Solutions:

    • Check LZ SKU Sync > Sync Log for queue status
    • Contact your hosting provider about server performance

    Duplicate Products¶

    Solutions:

    • Verify SKUs match exactly (case-sensitive) between Zoho and WooCommerce
    • Check "Create Missing Products" setting
