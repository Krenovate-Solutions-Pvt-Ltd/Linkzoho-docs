    Sync Log¶

    View and search all synchronization activities from the last 30 days.

    Accessing Sync Log¶

    Navigate to LZ SKU Sync > Sync Log in your WordPress admin panel.

    Understanding the Table¶

    Table Columns¶

    Column Description
    S.No Sequential number
    Action ID Unique job identifier
    Action Type Type of sync (Created, Updated, Image Upload, etc.)
    SKU / Group ID Product SKU
    Product Name Name from Zoho Inventory
    Product Type Simple, Group, or Variation
    Date & Time When the action occurred
    Action Status Pending, In-Progress, Complete, Failed, Canceled
    Action Logs Detailed execution logs

    Status Badges¶

    • 🟡 Pending - Queued, waiting to process
    • 🔵 In-Progress - Currently executing
    • 🟢 Complete - Successfully finished
    • 🔴 Failed - Encountered an error
    • ⚫ Canceled - User-canceled

    Search & Filter¶

    Search Box¶

    Type to search by: - Action ID, SKU, Product Name, Product Type, Action Status

    Filters¶

    • Action Status - Filter by Pending, Complete, Failed, etc.
    • Product Type - Filter by Simple, Group, or Variation
    • Date Range - From date and To date pickers

    Click Reset to clear all filters.

    Pagination¶

    • 10 items per page
    • Use navigation buttons at the bottom

    Using Sync Log for Troubleshooting¶

    Finding Failed Actions¶

    1. Set Action Status filter to Failed
    2. Check the Action Logs column for error details
    3. See Troubleshooting Guide for solutions

    Tracking a Specific Product¶

    1. Enter the SKU or Product Name in search
    2. Review all actions for that product

    Data Retention¶

    • Logs are kept for 30 days only
    • Older logs are automatically cleaned up
    • Take screenshots to save important records
