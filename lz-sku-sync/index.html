    LZ SKU Sync - Overview¶

    Automate Product Synchronization Between Zoho Inventory and WooCommerce

    What is LZ SKU Sync?¶

    LZ SKU Sync is a premium WordPress plugin that automatically synchronizes products, inventory levels, images, and attributes between Zoho Inventory and WooCommerce. Keep your online store always up-to-date with accurate information from Zoho.

    Key Benefits¶

    🚀 Save Time¶

    Stop manually updating product information in WooCommerce. LZ SKU Sync automates the entire process.

    ✅ Prevent Errors¶

    Eliminate data entry mistakes with automated synchronization using Zoho Inventory as the source of truth.

    📊 Real-Time Updates¶

    With webhook integration, changes in Zoho Inventory appear in your WooCommerce store within seconds.

    🖼️ Automatic Image Management¶

    Product images are downloaded and organized automatically.

    📦 Multi-Warehouse Support¶

    Sync inventory from specific warehouses in your Zoho account.

    Core Features¶

    Synchronization Modes¶

    • Manual Sync: One-click bulk synchronization
    • Real-Time Webhook Sync: Automatic synchronization when products change in Zoho

    Complete Product Support¶

    • ✅ Simple products
    • ✅ Variable products with attributes and variations
    • ✅ Product images (featured and gallery)
    • ✅ SKU-based matching

    Product Data¶

    • Product name and description
    • SKU and pricing
    • Stock quantities and status
    • Weight and dimensions
    • Product images

    Inventory Management¶

    • Multi-warehouse support
    • Real-time stock updates
    • Low stock notifications
    • Inventory overview dashboard

    Granular Control¶

    • Choose to create new products or only update existing
    • Control product status (Draft, Pending, Published)
    • Separate controls for simple products and variations

    System Requirements¶

    WordPress Environment¶

    • WordPress 4.7 or higher
    • PHP 7.4 or higher (8.0+ recommended)
    • WooCommerce 7.9 or higher

    Zoho Requirements¶

    • Active Zoho Inventory account
    • API access enabled (included in all plans)

    Getting Started¶

    1. Install & Activate - Upload the plugin and activate your license
    2. Initial Setup - Connect to Zoho Inventory
    3. Choose Sync Method - Select manual or webhook sync
    4. Configure Settings - Customize what data to sync
