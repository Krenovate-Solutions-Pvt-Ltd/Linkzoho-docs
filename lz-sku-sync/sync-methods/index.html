    Synchronization Methods¶

    LZ SKU Sync offers two ways to sync your products: Manual Sync and Real-Time Webhooks.

    Choose Your Sync Method¶

    Feature Manual Sync Webhook Sync
    Trigger Click "Start Sync" button Automatic when Zoho changes
    Timing On-demand Real-time (within seconds)
    Best For Initial setup, bulk updates Ongoing operations

    Manual Sync¶

    Best for initial setup, periodic bulk updates, or when you prefer full control.

    Start a Manual Sync¶

    1. Go to LZ SKU Sync > Sync Status
    2. Configure your sync preferences
    3. Click Start Sync
    4. Monitor real-time progress
    5. Review synced items as they complete

    Sync Controls¶

    • ⏸️ Pause - Temporarily stop sync (can resume later)
    • ▶️ Resume - Continue a paused sync
    • ❌ Cancel - Stop sync permanently (cannot resume)

    Progress Display¶

    During sync, you'll see:

    • Total Products - Number of products queued
    • Synced - Successfully processed
    • Failed - Products with errors
    • Pending - Waiting in queue
    • Progress Bar - Visual completion status

    Tip

    Sync continues in the background even if you close your browser.

    Real-Time Webhook Sync¶

    Best for ongoing operations where Zoho Inventory is your primary product management system.

    Enable Webhooks¶

    1. Go to LZ SKU Sync > Sync Status
    2. Find Sync Frequency setting
    3. Select "Always (Real-time webhook)"
    4. Click Save Preferences

    The plugin automatically configures everything in Zoho Inventory!

    Webhook Status¶

    • 🟢 Active (Green) - Receiving updates
    • 🔴 Inactive (Red) - Paused

    Click the status indicator to toggle on/off.

    Tip

    See Webhook Integration for detailed webhook setup and troubleshooting.

    Recommended Approach¶

    1. Initial Setup: Run a manual sync to import all products
    2. Ongoing: Enable webhook sync for real-time updates
    3. Periodic: Run manual sync occasionally to verify consistency

    What Gets Synchronized?¶

    Based on your Product Settings:

    • ✅ Product name and description
    • ✅ SKU and price
    • ✅ Stock quantity and status
    • ✅ Low stock threshold
    • ✅ Weight and dimensions
    • ✅ Product images
    • ✅ Product variations and attributes

    Troubleshooting¶

    Manual Sync Stuck¶

    • Check LZ SKU Sync > Sync Log for errors
    • Contact support if issue persists

    Webhooks Not Working¶

    • Check webhook status indicator (should be green)
    • Verify license is active
    • Review Sync Status > Webhook Sync Log
